# Pong Igra (C++ / Raylib)

Klasična Ping Pong igra izrađena u C++ jeziku uz korištenje Raylib knjižnice za grafičko sučelje.

## Kako pokrenuti projekt lokalno

### Preduvjeti
1. Instaliran C++ compiler (g++ / MinGW)
2. VS Code ili bilo koji drugi C++ uređivač koda

### Pokretanje
1. Klonirajte ili preuzmite ovaj repozitorij.
2. Otvorite mapu projekta u VS Code-u.
3. Pokrenite igru pritiskom na F5 (ili pokrenite Makefile naredbom `make` u terminalu).
